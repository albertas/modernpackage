# Task

Add an end-to-end test (in the `tests_e2e/` directory) that proves a scaffolded
fullstack application is functional by exercising a real "products" feature: a
products list page in the frontend backed by products persisted in the database.

The test must scaffold a fullstack package, add a products data model with
backend create/read endpoints and a frontend products page, run the whole stack,
and verify that products can be created and then read back through the frontend
page. This extends the existing e2e coverage from "the stack boots" to "a
database-backed feature actually works end to end."
