application scaffolding path. The test should scaffold a fullstack package and
verify the generated application is genuinely functional end to end — backend,
frontend, and their integration — rather than only confirming the scaffold is
produced. This gives confidence that the fullstack scaffolder emits a working
application, not just well-formed files.
