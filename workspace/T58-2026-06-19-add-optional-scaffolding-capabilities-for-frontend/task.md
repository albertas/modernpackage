# Task

Provide optional, opt-in scaffolding so the `modernpackage` CLI can generate a
fully functional FastAPI backend (`--backend`/`--fastapi`) and, additionally, a
React frontend (`--fullstack`/`--reactjs`) on top of the base Python package.
The default scaffold must remain free of any backend or frontend code, and the
generated backend and frontend must each be coherent, testable, and pass their
own checks when the flags are used.
