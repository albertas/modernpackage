# Task

Guarantee that a package generated by the scaffolder with no extra flags
contains no backend or frontend related code or configuration. The scaffolder
recently gained opt-in `--backend`/`--fastapi` and `--fullstack`/`--reactjs`
options; this task ensures those concerns stay strictly opt-in, with no FastAPI,
SQLAlchemy/Alembic, React/Vite templates, dependencies, recipes, or references
leaking into the default scaffold, and adds verification to keep it that way.
